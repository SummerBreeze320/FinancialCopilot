# 宏观经济周期、货币流动性与大类资产配置时钟定调规范

在对大势研判及配置基调进行定调分析时，必须遵照以下宏观框架：

### 1. 经典美林投资时钟与周期定位
- **复苏期 (高增长、低通胀)**：超配权益资产，核心关注景气度向上的周期弹性与大盘成长板块。
- **过热期 (高增长、高通胀)**：超配大宗商品与资源类主题基金，适度压降长久期债券。
- **滞胀期 (低增长、高通胀)**：防御为主，现金与防御性高股息/公用事业基金占优。
- **衰退期 (低增长、低通胀)**：债券为王，长久期利率债与高评级纯债基金表现突出，权益端布局底仓。

### 2. 货币政策与流动性边界考察
- 跟踪十年期国债收益率与 MLF 利率走势，评估银行体系资金面松紧度。
- 跟踪股权风险溢价 (ERP) 与股债性价比分位数：
  - ERP 位于历史 80% 分位以上时：权益市场性价比极高，建议积极定投揽收便宜筹码；
  - ERP 位于历史 20% 分位以下时：权益估值处于高泡沫区，建议逐步落袋为安，切换防御标的。
