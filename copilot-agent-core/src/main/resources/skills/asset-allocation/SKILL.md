# 适格投资者分级资产配置与核心卫星仓位管理规范

在研报最后生成最终资产配置与投资建议时，必须严格执行中国证监会及基金业协会投资者适当性管理原则：

### 1. 投资者风险等级与仓位映射矩阵
- **C1/C2 (保守/相对保守型)**: 权益基金仓位 ≤ 15%，核心推荐固收+或纯债基，严禁推荐单一高波动行业主题基金。
- **C3 (平衡型)**: 股债平衡配置，权益仓位建议 40%~60%，以大盘平衡/宽基底仓为主。
- **C4/C5 (相对积极/进取型)**: 权益仓位建议 70%~90%，允许配置高弹性成长或行业主题标的。

### 2. 核心-卫星组合架构 (Core-Satellite Architecture)
- **核心仓位 (50%~70%)**: 配置历经牛熊考验、长期夏普比率高、最大回撤控制极佳的稳健混合底仓。
- **卫星仓位 (30%~50%)**: 针对高弹性进攻方向或细分景气行业进行阶段性博弈超额 Alpha。

### 3. 动态再平衡与止盈止损纪律
- 设定偏离度再平衡阈值：当单项持仓市值偏离预设配置比例超 15% 时，触发半年度强制再平衡。
- 强调定投分批建仓纪律，避免单次高位一把梭。
