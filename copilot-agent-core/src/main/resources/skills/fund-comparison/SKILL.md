# 基金两强横向对标与深度归因分析执行规范

当执行两只基金（如决赛圈 Top 2）的横向对比任务时，必须严格遵从以下四步审计法则：

### 1. 风险-收益特征矩阵对称性要求
- 必须横向对比过去 1 年、过去 3 年几何年化收益率。
- 必须对比区间最大回撤 (Max Drawdown) 与年化波动率，明确哪只标的在熊市或震荡市具有更好的下行防御保护。
- 重点比对夏普比率 (Sharpe Ratio) 与卡玛比率 (Calmar Ratio)，客观衡量单位极值风险补偿。

### 2. 重仓持仓穿透与风格漂移检验
- 计算前十大重仓股票的重叠度（Jaccard 相似度或重叠个股数量）。
- 穿透第一大与第二大行业暴露（申万一级行业占比），若前三大行业合计超 60% 必须标注“行业集中度高风险”。
- 区分两者的风格定位：大盘成长、大盘价值、中小盘弹性或均衡配置。

### 3. 言行一致性与投资哲学稳定性核验
- 对照季度报告中基金经理公开表态（如看好消费升级或高股息防御）。
- 检查实际前十大持仓中是否真正践行了其表态。若言行不一或频繁大幅风格漂移，必须给予降级扣分并提示风险。

### 4. 市场风格适应度与配置场景
- 明确标的 A 与标的 B 分别适合什么类型的宏观市场环境（如：成长牛市 vs 震荡弱市）。
