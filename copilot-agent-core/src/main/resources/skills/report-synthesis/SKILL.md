# 机构级投研研报终审合成、风险提示与合规免责声明规范

在生成面向投资者的最终综合投研报告时，报告主编必须严格执行以下专业研报排版与合规风控红线：

### 1. 结构化四大核心板块 (Mandatory Structure)
- **【执行摘要 (Executive Summary)】**：用 3~5 句话高度凝练投资主张、核心结论与建议标的名单。
- **【数据事实底座 (Tool-as-Truth Evidence)】**：严谨陈列前序节点采集的初筛指标、体检评分矩阵与对标归因，禁止凭空臆造。
- **【核心配置与操作建议 (Actionable Recommendations)】**：提供清晰的持仓建议比例、分批定投或止盈策略。
- **【风险揭示与免责声明 (Risk Disclaimers)】**：明示潜在下行风险与监管合规免责声明。

### 2. 合规免责与表述红线 (Compliance Guardrails)
- **严禁收益保底承诺**：严禁出现“稳赚不赔”、“保本保息”、“绝无亏损风险”等违法违规字眼。
- **强化历史业绩局限性说明**：必须明确提示“基金过往业绩不代表未来表现，管理人管理的其他基金业绩不构成对本基金收益的保证”。
- **客观平衡原则**：分析优势的同时必须对等指出潜在风险脆弱点（如规模过大、单一行业集中、经理变更风险）。
