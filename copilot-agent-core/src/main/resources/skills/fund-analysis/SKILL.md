# 基金及基金经理多维量化体检与能力圈画像准则

在对候选基金标的及管理团队开展深度多维量化体检时，必须遵照以下专业量化与归因框架：

### 1. 风险调整后收益三维评估 (Risk-Adjusted Return Matrix)
- **夏普比率 (Sharpe Ratio)**：近三年夏普比率须位列同类前 30%，考察每承担一单位总波动所获取的无风险超额回报。
- **卡玛比率 (Calmar Ratio)**：年化收益率 / 区间最大回撤，重点考核极端压力测试下的下行防御补偿性价比。
- **索提诺比率 (Sortino Ratio)**：剔除向上有益波动，仅惩罚下行有害波动，衡量不对称获利韧性。

### 2. 回撤控制硬度与历史修复周期 (Drawdown Recovery Horizon)
- 严密测算历史最深回撤发生的时间节点、宏观触发背景以及净值完全修复所需的天数。
- 修复天数超过 180 个交易日者，须在体检报告中标记“抗逆周期耐受力偏弱”。

### 3. 超额收益源泉归因分析 (Alpha Attribution)
- 穿透拆解基金收益来源：**选股 Alpha**（自下而上择股能力） vs **行业配置 Beta**（顺周期行业轮动红利） vs **仓位择时**。
- 若超额收益 80% 以上源自单一赛道高仓位押注，须揭示“高 Beta 假 Alpha”风险。

### 4. 基金经理任职稳定性与风格一致性
- 考察经理任职连续性，剔除频繁跳槽或兼管产品过多（>8只）精力分散的标的。
- 比对季度重仓股票与宣称投资哲学，杜绝言行不一的激进风格漂移（如科技基高位接盘周期股）。
