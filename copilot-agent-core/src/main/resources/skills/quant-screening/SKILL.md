# 公募基金量化初筛硬性准入与异常风控剔除准则

在执行候选标的池初筛阶段时，必须遵照以下硬性量化排除法：

### 1. 存续时间与稳定性门槛
- 剔除成立时间不满 3 年的次新基金产品（避免仅凭短期运气或特定行情高收益产生的幸存者偏差）。
- 剔除现任基金经理任职不满 1 年的标的，确保业绩可归因于当前管理者。

### 2. 基金规模边界与流动性考量
- 规模 < 1 亿元：警惕清盘风险或高换手打新异动，原则上予以剔除。
- 规模 > 150 亿元：警惕“规模是业绩的杀手”，大盘基金换手与建仓摩擦成本过大，须额外关注其持仓流动性。

### 3. 极值风控指标剔除
- 过去 3 年最大回撤超过同类偏股基金均值 1.5 倍者，直接从初筛候选池剔除。
