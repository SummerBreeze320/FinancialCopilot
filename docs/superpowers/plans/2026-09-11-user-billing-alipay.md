# 用户隔离、计费与支付宝接入

用户已选择原整改清单第 4 项，并指定接入支付宝。沿用现有 Spring Boot、MyBatis-Plus 和 PostgreSQL，不重建工作流。

- [x] 用户隔离：从登录上下文取 UID；拒绝不匹配的兼容 userId 参数；会话存储键由 UID 和客户端会话 ID 构成；匿名调用失败。用 HTTP/控制器测试验证越权读写被拒绝。
- [x] 计费一致性：移除数据库异常时的内存钱包兜底；扣款与流水同事务；不足余额不写成功流水；使用模型返回的 usage、provider、model 按实际调用计费。覆盖同步、SSE、无 usage、Mock 与数据库失败。
- [x] 支付宝：官方 SDK 公钥模式 RSA2 验签；核对 app_id、seller_id、total_amount、out_trade_no、trade_status；订单行锁、充值与状态同事务；重复通知幂等。关闭旧 JSON 回调，提供登录用户专属的电脑网站支付跳转地址及表单通知端点。
- [x] 验证与文档：本地 RSA 签名通知测试；真实 PostgreSQL 并发及回滚测试；全量测试；凭据仅环境变量，缺失时拒绝支付。没有商户凭据时不声称完成支付宝实网验收。

后台记忆提纯属于系统维护调用，不从用户钱包扣款。支付前端和真实商户签约不在本次代码修改范围内。
